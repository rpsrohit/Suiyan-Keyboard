# Suiyan Keyboard 🚀

Custom Android Keyboard with Multiple Fonts & Leet Mode!

## Features ✨
- ✅ 5 Font Styles (Normal, Bold, Italic, Mono, Serif)
- ✅ CAPS Lock Mode
- ✅ L33T Mode (A→4, E→3, I→1, O→0, S→5, T→7)
- ✅ Delete & Space buttons

## Build with CodeMagic
1. Go to https://codemagic.io
2. Sign in with GitHub
3. Connect this repo
4. Click "Start your first build"
5. Download APK

## Install on Phone
1. Download APK
2. Tap APK on phone
3. Install
4. Settings > Languages & Input > Input Methods
5. Enable "Suiyan Keyboard"

## Usage
- Font Buttons: Change style
- CAPS: Permanent capitals
- L33T: Leetspeak conversion
